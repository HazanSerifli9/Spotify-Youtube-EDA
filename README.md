# Spotify and YouTube Analysis 



Overview

This project explores and analyzes data from Spotify and YouTube, focusing on uncovering insights into music trends, artist performance, and audience engagement. The dataset was sourced from Kaggle, and this repository contains the data processing, exploratory data analysis (EDA), visualizations, and findings. The link : https://www.kaggle.com/datasets/salvatorerastelli/spotify-and-youtube?resource=download

Contents

Data Description: Details about the dataset and its features.
Exploratory Data Analysis (EDA): Initial findings and insights into Spotify and YouTube data trends.
Visualizations: Interactive charts and graphs highlighting key aspects of the data.


Dataset

The dataset includes information such as:

Spotify: Track names, artists, popularity, and audio features (e.g., danceability, tempo).
YouTube: Video titles, channel names, views, likes, and engagement metrics.
